# Bối cảnh dài hạn

Lamix OS là dự án OS Gaming native x86_64, do người dùng chốt baseline và trình tự milestone. Tài liệu gốc là [ROADMAP.md](../ROADMAP.md); ba tệp prompt tại root hỗ trợ mở phiên và bàn giao, không phải bằng chứng triển khai.

## Tìm nguồn sự thật

| Câu hỏi | Tài liệu |
|---|---|
| Mục tiêu, thứ tự, phụ thuộc dài hạn | [ROADMAP](../ROADMAP.md) |
| Phạm vi triển khai đang duyệt | [PLANS](../PLANS.md) |
| Vì sao có quyết định kiến trúc | [DECISIONS](DECISIONS.md) |
| Thay đổi thực sự đã làm | [CHANGELOG](../CHANGELOG.md) |
| Trạng thái và bước tiếp tục phiên | [SESSION_HANDOFF](SESSION_HANDOFF.md) |

Không sao chép trạng thái phiên vào tài liệu bối cảnh. Khi code và baseline khác nhau, báo khác biệt và xin duyệt thay vì tự đổi baseline.
