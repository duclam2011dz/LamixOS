# Kiến trúc

**Phần lớn subsystem chưa triển khai.** Kernel bootstrap M08, Bitmap PMM M09, VMM BSP M10, kernel heap M11, Buddy PMM thử nghiệm M12, ACPI/PCI/device framework cơ bản M13, APIC/timer M14, input M15, software renderer M16, VirtIO-GPU 2D M17, scheduler BSP M19, process/ring 3 M20 và syscall ABI v1 M21 đã DONE. M22 handles/channels/SHM đã nghiệm thu trong profile riêng. M23 Static PIE ELF64 loader/runtime đã nghiệm thu và chỉ bật trong profile M23. M24 SMP, M25 block abstraction/VirtIO-Blk và M26 VFS/tmpfs/FAT32 đã nghiệm thu trong profile riêng; M27 services/shell đang nghiệm thu riêng; `latest` vẫn trỏ M26; profile M25 và BSP-only vẫn chọn tường minh. M12 giữ bitmap làm backend mặc định; M18 vẫn PLANNED; kernel sản phẩm chưa có. M13 guest không cấp RSDP trong LBP nên ACPI traversal guest **NOT RUN**. Baseline kiến trúc nằm ở [roadmap, mục 1](../ROADMAP.md).

Bootloader BIOS và UEFI tự viết → LBP/BootInfo chuẩn hóa → một kernel entry chung. Hybrid Kernel cung cấp quản lý bộ nhớ, scheduler, processes/threads, capabilities, IPC và syscalls. Duy trì cả kernel-mode drivers và user-mode drivers lâu dài; không chuyển toàn bộ driver ra user-space.

User-space gồm services, compositor/window manager, SDK và games native. Storage đi từ VFS/FAT32/tmpfs đến LamFS; audio, networking, packaging và A/B updates theo milestone muộn trong roadmap.

BSP-only trước SMP; PIC bootstrap → APIC/IOAPIC → MSI/MSI-X. M19 scheduler BSP đã nghiệm thu preemptive priority round-robin qua LAPIC timer. M20 thêm process một thread/address space riêng và user-mode test payload. M21 bổ sung syscall ABI x86-64; M22 đã mở rộng ABI lên 1.1 trong profile khác. M23 thử nghiệm ET_DYN Static PIE, fixed load bias, `R_X86_64_RELATIVE`, newc initramfs và runtime tối thiểu trong profile riêng. M24 đã nghiệm thu xAPIC AP startup, per-CPU scheduler, GS entry/return handling và TLB shootdown trong `m24-kernel`. M25 thêm block I/O VirtIO-Blk trong `m25-kernel`; M26 thêm VFS, tmpfs và FAT32 trong `m26-kernel`. `latest` trỏ M26; profile M25 và các profile cũ vẫn chọn tường minh. Không đổi LBP v1/entry ABI. M18 GPU 3D PoC vẫn PLANNED/để dành, không phải dependency.

M26 đã nghiệm thu VFS kernel nội bộ với tmpfs root và FAT32 trên GPT User Data tại `/data`, dùng block device M25. FAT32 hỗ trợ 8.3/LFN và directory lồng nhau; rename directory trả `VFS_UNSUPPORTED`; filesystem không được expose qua syscall trong M26. M27 profile riêng cung cấp init/service lifecycle, shell, ABI 1.2 wrappers và rights subset được cấp qua manifest bằng `lamix_process_spawn_with_rights`; spawn không chuyển quyền mặc định. Guest BIOS/UEFI đã kiểm tra serial/PS2, framebuffer và reboot persistence. `LATEST_PROFILE=m26`; M18 vẫn PLANNED, M27 chưa nghiệm thu và M28 chưa bắt đầu.
